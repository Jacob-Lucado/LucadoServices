Privacy policy

Last updated October 26, 2026

This policy covers this website only. Steam Value Checker and FanaticalGrabber each have their own privacy policy, linked below, because they handle data differently.

The short version

This website has no accounts, no forms, no cookies, no analytics and no advertising. I don't collect anything about you through it.

What this website does

  • It is a set of static pages. Nothing you type here is sent anywhere.
  • It doesn't set cookies and doesn't use trackers, analytics or advertising scripts.
  • Its fonts and images are served from the same site. It doesn't load fonts or scripts from third parties.
  • It doesn't take payments. The shop page is a placeholder.

Who hosts it

The site is hosted on GitHub Pages. Like any web host, GitHub receives your IP address and basic request details when you load a page, and may keep logs. That happens on GitHub's side, and I don't receive or control that data. See GitHub's privacy statement.

Links to other sites

This site links to GitHub, X, Discord and the tools' own pages. Once you follow a link, that site's policy applies, not this one.

The tools

  • FanaticalGrabber: privacy policy. It runs in your browser.
  • Steam Value Checker: run /privacy in Discord, or read the privacy document. You can export or delete your data with /mydata.

Children

This site isn't aimed at children under 13, and it doesn't knowingly collect anything from anyone.

Changes

If this policy changes, the date at the top changes. If I ever add something that collects data, such as a shop checkout, I'll update this page before it goes live.

Contact

Questions about privacy? Message me on X or open an issue on GitHub.
